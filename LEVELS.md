# Level progression

1. Change user ownership with `sudo chown`.
2. Change group ownership with `sudo chgrp`.
3. Repair a file mode with `sudo chmod`.
4. Repair directory listing and traversal permissions.
5. Secure a simulated employee home directory.
6. Diagnose and repair a parent-directory traversal defect.
7. Configure setgid inheritance on a shared directory.
8. Repair a shared workspace's group, access, and setgid policy.
9. Perform a constrained ownership and mode repair without changing decoys.
10. Complete a multi-object company permissions audit.
